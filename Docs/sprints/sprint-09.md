# Sprint 9: consumo del backend con Retrofit

*9 al 13 de octubre de 2026*

## Qué pedía

Que la app tome sus datos de un servicio REST propio.

## Qué se hizo

- La app deja los datos locales y consume el backend de Express ([mixtapp-backend](https://github.com/AndresContreras1/mixtapp-backend)) con Retrofit.
- Inicio con todos los álbumes, detalle con sus reseñas y el perfil con solo mis reseñas, que se editan desde ahí.
- Las correcciones del profesor: todo sale del backend y nada queda quemado en la app.

## Cómo se prueba

Con el backend corriendo, la variante Retrofit muestra el catálogo y las reseñas que entrega la API.
